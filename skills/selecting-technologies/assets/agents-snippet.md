## Technology choices

For a new framework, datastore, language, hosting service, model provider, public
protocol, or other sticky dependency, inspect the project and write an ADR before
committing to it. Compare at least two viable options, verify current support and
license facts from official sources, record the check date, and define the first
validation step and an exit path. Do not add a dependency because it is fashionable
or because the model remembers it.
