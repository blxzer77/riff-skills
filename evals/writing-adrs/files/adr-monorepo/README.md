# readwell

Reading-list app. npm workspaces:

- `packages/api` — REST/GraphQL API on Lambda (Prisma + Postgres)
- `packages/worker` — background jobs
- `packages/desktop` — Electron app with local SQLite
- `packages/web` — React front end
- `packages/cli` — admin CLI
- `services/gateway` — Express gateway, LLM features

Decisions live in `docs/adr/`.
